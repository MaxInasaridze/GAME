# 67 Papiko

Georgian arcade timing game: stop the counter at 67.00. Includes optional synthesized sound, recent attempts and a best accuracy record stored in the current browser. No shared leaderboard or backend database.

Requires Node.js 20 or newer. No dependencies.

Run `npm start` and open http://localhost:3000. Build with `npm run build`.

Vercel: import this repository; vercel.json configures the static build.
Render: create a Blueprint from this repository, or create a Static Site with build command `npm run build` and publish directory `dist`.

Both hosts serve the same complete game. Records are local to each browser and domain.
